## Atividades

### Atividade 1 — Ingestão ETL Visual

Implementação de um processo de ingestão e transformação de dados utilizando uma ferramenta visual de ETL.

A atividade contempla etapas de:

- ingestão dos dados;
- transformação e tratamento;
- integração das informações;
- preparação dos dados para utilização posterior.

### Atividade 2 — Ingestão ETL com Python

Implementação de um pipeline de ingestão utilizando Python, contemplando a leitura, tratamento e organização dos dados.

O objetivo é demonstrar a aplicação de técnicas de Engenharia de Dados para construção de um processo automatizado de ingestão.

## Tecnologias e ferramentas

- Python
- Git / GitHub
- Visual Studio Code
- Ferramentas de ETL
- Processos de ingestão e transformação de dados
